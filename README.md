# Бинго

Логопедическая игра для двух игроков на одном экране. Откройте `index.html` в современном браузере. Установка и сборка не нужны.

1. Выберите условие победы. По умолчанию нужно закрыть строку, столбец или любую из двух диагоналей. Во втором режиме нужно закрыть все клетки.
2. Активный игрок достаёт карточку. Если такой картинки на его поле нет, он достаёт следующую.
3. Найдите совпадение, выполните задание вслух и нажмите на окно задания. Программа поставит фишку и передаст ход либо объявит победителя.
4. «Начать заново» раздаёт новые поля и сохраняет выбранное условие. После перезапуска условие можно поменять до первого вытягивания.

`content.js` содержит размер поля, каталог карточек с постоянными идентификаторами и отдельный список заданий. Для поля 4×4 нужно минимум 16 уникальных карточек и хотя бы одно задание. `game.js` управляет ходами, колодами и победой. `app.js` связывает правила с браузерным интерфейсом, а `styles.css` задаёт оформление и вид фишек.
