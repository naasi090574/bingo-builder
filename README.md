# Бинго

Редактор логопедической игры для двух игроков. Откройте `index.html` в современном браузере. Установка и сборка не нужны. В редакторе доступны восемь разделов и интерактивный предпросмотр. Наполнение разделов настройками будет добавляться поэтапно. Кнопка «Предпросмотр игры» открывает `game.html` в новой вкладке.

1. В разделе «Настройки игры» задайте название, имена двух игроков, размер поля от 2×2 до 5×5, порядок заданий и условие победы. Изменения сразу запускают новую партию в предпросмотре.
2. Активный игрок достаёт карточку. Если такой картинки на его поле нет, он достаёт следующую.
3. Найдите совпадение, выполните задание вслух и нажмите на окно задания. Программа поставит фишку и передаст ход либо объявит победителя.
4. «Начать заново» раздаёт новые поля с теми же настройками. Последовательные задания после последнего начинаются с первого.

`settings.js` задаёт значения по умолчанию и читает параметры запуска. `content.js` содержит каталог карточек с постоянными идентификаторами и отдельный список заданий. `game.js` управляет ходами, колодами и победой. `app.js` связывает правила с браузерным интерфейсом, а `styles.css` задаёт оформление и вид фишек.

Временные иллюстрации взяты из [Noto Emoji](https://github.com/googlefonts/noto-emoji), © Google Inc. и авторы проекта. Лицензия изображений [Apache 2.0](assets/LICENSE).

### Дополнительные шрифты

Все девять списков шрифтов в редакторе используют общий каталог в `appearance.js`. Сейчас в нём системный шрифт, Arial, Georgia и Courier New. Для четырёх дополнительных гарнитур в проекте пока нет файлов, лицензий и правил `@font-face`.

Для подключения нужны оригинальные файлы `.ttf`, `.otf` или `.woff2` с кириллицей. Для каждого файла приложите исходную лицензию SIL Open Font License из комплекта, сведения об авторе и ссылку на авторский релиз.

| Шрифт | Какой файл нужен | Статус разрешения |
| --- | --- | --- |
| Gogono Cocoa Mochi Cyrillic | Кириллическое начертание Regular | Разрешение для конкретной кириллической версии не подтверждено. |
| Itim Cyrillic | Кириллический Regular v1.002, адаптация Дениса Игнатова | OFL указана на [странице версии](https://localfonts.eu/freefonts/handwritten-cyrillic-free-fonts/itim-cyrillic/). Нужен исходный архив с файлом и лицензией. |
| Ruthless Sketch Italic | `RuthlessSketch-Italic.ttf` или оригинальный OTF/WOFF2 того же начертания | OFL 1.1 указана на [странице авторского выпуска GGBotNet](https://ggbot.itch.io/ruthless-sketch-font). Нужен исходный архив с файлом и лицензией. |
| Sol Kol | Оригинальный файл гарнитуры Amina Nugymanova | Авторство указано в [портфолио](https://dprofile.ru/case/180686/sol-kol-rukopisnyi-srift). Разрешение для конкретного файла не подтверждено. |
